# Domain docs

Single-context repo. Read what touches your area before working:

- [`CONTEXT.md`](../../CONTEXT.md): glossary. Use its terms, not the synonyms it lists under _Avoid_. If a concept you need is missing, add it there.
- [`docs/decisions/`](../decisions/): ADRs. Immutable: to change one, add a superseded note. If your work contradicts an ADR, say so explicitly rather than silently overriding it.
- [`docs/design/`](../design/): per-subsystem specs (matching, library, data safety, services etiquette, ...).
- [`src/mixsync/README.md`](../../src/mixsync/README.md): module map and dependency rules.
